# Архитектура Purple Shift

Этот файл фиксирует границы модулей после версии 2.1. Старые файлы с названиями версий остаются на месте ради совместимости меток, сохранений и уже написанных тестов. Новая логика добавляется в каталоги по назначению, а не в очередной `*_shift.rpy`.

## Основные слои

| Слой | Файлы | Ответственность |
|---|---|---|
| Сценарий недели | `game/script.rpy`, `game/chapter3.rpy`, `game/week.rpy` | Главы 1–7, основные решения и семь финалов |
| Маршруты | `game/routes/living_routes.rpy` | Личные сцены шестого дня, аварийные развязки и восемь маршрутных эпилогов |
| Состояние и правила | `game/systems.rpy`, `game/polish.rpy`, `game/traces.rpy` | Характеристики, отношения, архив, достижения и выбор главы |
| Совместимость | `game/core/save_migrations.rpy` | Схема сохранения и безопасное добавление новых полей после загрузки |
| Представление | `game/characters.rpy`, `game/screens.rpy`, `game/gui.rpy` | Образы, трансформации, стандартный интерфейс и экраны |
| Наследуемые расширения | `game/*_shift.rpy`, `game/director.rpy` | Системы версий 1.2–2.0, оставленные стабильными для совместимости |
| Проверки | `game/testcases.rpy` | Экранные, системные, маршрутные и параметризованные тесты Ren’Py |

## Поток личного маршрута

1. Решения недели изменяют `ps_route_points` и `ps_route_tendencies`.
2. `ps_route_target()` выбирает героя с наиболее сильной связью.
3. `ps21_route_night_scene` фиксирует выбор роста или тени на шестом дне.
4. `ps21_route_finale_setup` возвращает этот выбор перед аварией.
5. `ps21_route_emergency_payoff` даёт герою самостоятельное действие в аварии.
6. `ps21_route_epilogue` открывает один из восьми постоянных исходов.

Основные финалы и личные исходы намеренно независимы: один описывает решение главного героя о складе, второй — изменение конкретного человека рядом с ним.

## Правила состояния

- Новые переменные прохождения объявляются через `default`.
- Постоянная коллекция хранится в `persistent.ps21_route_outcomes`.
- Новое поле обязательно добавляется в `ps_migrate_loaded_save()` и сбрасывается в `ps_prepare_chapter()`.
- Сценарная метка не должна напрямую изменять `persistent`, кроме функции открытия коллекционного результата.
- Совместимые старые метки сохраняются как небольшие переходники; `ps2_route_crisis` теперь вызывает актуальную маршрутную сцену.

## Добавление нового контента

- Новый маршрутный эпизод: `game/routes/`.
- Общая инфраструктура или миграция: `game/core/`.
- Переиспользуемый экран: тематический модуль либо `game/screens.rpy`.
- Изображение персонажа сначала регистрируется в `game/characters.rpy`.
- Для каждой новой метки, функции, карточки и ресурса добавляется проверка в `game/testcases.rpy`.
