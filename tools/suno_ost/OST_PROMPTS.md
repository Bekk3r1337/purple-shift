# Purple Shift - Suno OST Production Pack

Цель: единый саундтрек, который звучит как одна игра, а не как набор случайных генераций.

## Общий звуковой язык

- dark cinematic ambient
- restrained industrial electronics
- melancholic piano fragments
- low analog synth pads
- distant metallic resonance
- subtle glitch / signal artifacts
- grounded warehouse atmosphere
- violet anomaly feeling without fantasy-orchestra bombast
- dialogue-friendly dynamics
- no trailer braams, no EDM drops, no heroic blockbuster percussion
- instrumental tracks should have clean intros/outros and be easy to loop

Для всех инструментальных треков в Suno включать **Instrumental**.

## 01 - Purple Shift
**Файл:** `game/audio/ost/01_purple_shift_main.mp3`  
**Назначение:** главное меню / музыкальная тема игры  
**Style:**
`dark cinematic ambient, post-industrial, melancholic piano, analog synth, subtle glitch, restrained, nocturnal, mysterious, visual novel soundtrack`

**Prompt:**
> Main theme for a serious cinematic visual novel set around a night warehouse and an impossible violet storm. Slow, hypnotic and melancholic. Sparse piano notes, warm low analog pads, distant metallic warehouse resonance, faint electrical hum, subtle signal glitches and a memorable four-note motif that can return throughout the soundtrack. Beautiful but uneasy, human rather than cosmic, no huge percussion, no EDM drop, no trailer music. Leave space for menu ambience and dialogue-like silence. Strong identity, elegant 2-3 minute instrumental.

## Экспорт

Скачивать итоговые версии в MP3 и переименовывать строго по именам выше.

После помещения файлов в `game/audio/ost/` игра автоматически начнёт использовать их там, где подключён OST helper. Старые треки остаются fallback, поэтому отсутствующий новый файл игру не ломает.
