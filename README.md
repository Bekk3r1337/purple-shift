# 🎮 Purple Shift — Visual Novel Game

Purple Shift — это визуальная новелла в сеттинге склада Wildberries, совмещающая аниме-стиль, юмор, драму и элементы симуляции.

## 📌 Особенности игры
- сюжет на основе реального опыта работы
- собственные персонажи и спрайты
- система выбора
- глава 1 полностью готова
- глава 2 — в разработке
- сюжетная вселенная PurpleShift

## 🛠 Технологии
- Ren'Py (Python)
- ATL Animation
- GUI кастомизация
- Story scripting
- Asset pipelines

## 📂 Файлы проекта
Игровые сценарии находятся в:

game/screens.rpy
game/characters.rpy
