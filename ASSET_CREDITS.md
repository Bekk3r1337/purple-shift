# Ресурсы и происхождение

Код, сценарий и файлы проекта распространяются на условиях корневой лицензии [MIT](LICENSE), если для конкретного ресурса не указано иное. Этот реестр отделяет воспроизводимые и документированные материалы от унаследованных файлов, происхождение которых ещё нужно подтвердить перед коммерческим выпуском.

## Документированные ресурсы

| Ресурс | Происхождение | Обработка |
|---|---|---|
| `game/audio/live/*.ogg` | Процедурно создано внутри проекта | Детерминированный генератор `tools/generate_soundscape.py`, Python + FFmpeg, без сторонних записей |
| `game/images/ch/nov_determined.png` | Создано для версии 2.1 с помощью OpenAI image generation по проектному спрайту `nov_relief.png` | Сохранена идентичность Леры, изменена эмоция; фон преобразован в прозрачный альфа-канал |
| `game/images/ch/vet_injured.png` | Создано для версии 2.1 с помощью OpenAI image generation по `vet_concerned.png` | Сохранена идентичность Виктора, добавлены усталость и травмированная кисть; прозрачный фон |
| `game/images/ch/mem_open.png` | Создано для версии 2.1 с помощью OpenAI image generation по `mem_serious.png` | Сохранена идентичность Макса, добавлена открытая уязвимая эмоция; прозрачный фон |
| `game/images/ch/super_conflicted.png` | Создано для версии 2.1 с помощью OpenAI image generation по `super_stern.png` | Сохранена идентичность Артёма, добавлен внутренний конфликт; прозрачный фон |

Для четырёх новых спрайтов использовалась одна схема запроса: сохранить лицо, волосы, одежду и силуэт исходного персонажа; создать конкретное эмоциональное состояние в серьёзной стилистике визуальной новеллы; исключить фон, текст и водяные знаки.

## Унаследованные ресурсы

Фоны, CG, исходные спрайты и MP3/OGG вне `game/audio/live/` уже находились в репозитории до версии 2.1. В проекте нет исходного реестра их авторов, генераторов или ссылок на лицензии. Версия 2.1 не меняет их заявленный статус и не приписывает им новое происхождение.

Перед платным распространением автору проекта следует заполнить для этих файлов источник создания и подтверждение права на публикацию. До этого корневая MIT-лицензия описывает условия репозитория, но сама по себе не доказывает происхождение стороннего медиа.
